# Compatibility status

| Evidence | Status |
|---|---|
| Device slots `0x1c8` and `0x218` | `victory-gpu/src/device.rs` records an observed four-argument call shape and an `ID3D12PipelineState` request. The descriptor layouts are unverified. Both return `E_NOTIMPL` with a cleared output. Known graphics, compute and mesh paths use the existing host pipeline builders. |
| Compute shader translation | The targeted baseline repeats 22 compute refusals. Ten lack a Wave32 lowering, seven encounter divergent reductions, three exchange lane masks under divergence and two read the first active lane under divergence. The exact 32-lane cascade lowering covers a subset of Wave64. Legacy `v_mad_legacy_f32` and `v_mac_legacy_f32` use fused arithmetic with flushed inputs. The `v_mad_legacy_f32` path passed a GPU comparison with a CPU reference. |
| Descriptor heap | `descriptor/host.rs` caps a 1,245,184-slot guest request to 1,000,000 host slots. Guest indices beyond the cap are not generally preserved. Existing per-draw table binding and byte-range handling are a starting point for fixtures. |
| Buffer views | `descriptor/host.rs` and `shadow.rs` validate typed/structured offsets and offer exact backing for supported ranges. The baseline logged one CBV off the 256-byte boundary, one SRV at offset 9 with a 64-byte element, and one UAV at offset 7 with a 32-byte element. Existing exact copies require a dword-aligned guest start. A fallback for unaligned addresses needs coverage for byte-accurate uploads and overlapping GPU writes before it can replace null views. |
| Queue slot `0xb8` | `queue.rs` documents a likely newer-layout suspend slot. The warning was recorded during normal close, followed by exit code 0. The signature and fence contract need verification. |
| Other object slots | `object.rs` reported pipeline state `0x58` and command list `0x1a8` at startup. Their contracts remain unverified. |
| Indirect work | `indirect.rs` and `list.rs` handle supported signatures and count buffers. The baseline still dropped approximately 616 indirect operations per frame. WARP tests cover count buffers, group ordering and both budget policies. A repeated command sharing one clamped argument record is still admitted as a group. |
| Ray tracing | `pipeline.rs` keeps the BVH builder gated by default. The offline Wave32 probe emitted, validated and created compute pipelines for all 52 programs. Six intersection fixtures passed. `1e71efa` gives each view heap its own directory reservation and preserves all guest address bits in two list keys. A separate GPU producer and consumer recorded through the runtime directory followed a GPU-written pointer between pages and published exact guest result bytes after the queue completed. Full builder stages, traversal integration, alias and remap cases, and production size and counter contracts remain open. |
| Texture and lighting | The baseline showed blocky shading around the hair and over 200 texture uploads triggered by changes without a notification. The inspected mip-drop-1 frames lacked the blocky outline, while dark surfaces persisted. The common benchmark still uses the upstream ambient stand-in at 0.3. The log confirms it records into the Radiance, Air and Resolve stages in the control. A separate guest-lighting probe can isolate its effect. The underlying lighting fault remains open. |
| CPU emulation | `console_insn.rs` and `crash.rs` contain CLZERO loop and MONITORX/MWAITX paths. The warnings alone do not establish a throughput cost. |
| Cache | `shader_cache.rs` keys on source and translation settings. `pipeline/library.rs` relies in part on the host driver rejecting incompatible pipeline-library blobs. Driver-change and interrupted-write cases need testing. |
| Host capabilities | `host.rs` queried and logged a Wave32-only host. It already probes Shader Model 6.6 for GPU-generated shaders and GPU upload heap support. Other adapter capability and validation comparisons remain open. |

## Phase 2 candidate

The diagnostics release compiles with sparse descriptor sweep iteration, typed indirect rejection diagnostics, sampled readback attribution, and named lighting resource extents. The descriptor fallback still handles lifetime, reuse and remapping cases without a validated incremental invalidation path. Readback traces measure transfer and write publication. These traces do not tell which guest CPU reads consume the result. The 1920×1080 swapchain is confirmed. Lighting-buffer dimensions are separate evidence from scene and upscaler extents.
